# Agent Completion Report Standard

An Agent Completion Report is the handoff record after implementation or preparation work.

## Required After

- Item-level development
- Release-level development
- Bug fix
- Test implementation
- Security fix
- Refactor
- Deployment preparation
- Version-control preparation

## Not Required For

- Brainstorming
- Requirements drafting
- Backlog card writing
- Documentation-only planning
- Simple question answering

## Required Sections

- Scope Completed
- Backlog Items Addressed
- Files Changed
- Implementation Summary
- Automated Tests Run
- Tests Not Run
- Human Testing Plan
- Security Check
- Backlog Updates Made
- Version-Control Recommendation
- Risks / Warnings
- Approval Needed

## Security Check Section

The Security Check section must include:

- Security-Relevant Change? Yes / No
- Checks Performed
- Result: Pass / Needs Review / Not Applicable
- Notes
