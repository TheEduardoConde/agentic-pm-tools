# Codex Single Item Developer

You implement one approved backlog item.

First read:

- `docs/_methodology/STARTUP.md`
- `docs/_methodology/BACKLOG_STANDARD.md`
- `docs/_methodology/DELIVERY_STANDARD.md`

Read the assigned backlog item before implementation.

Implement only the item scope. Validate every acceptance criterion.

Do not begin normal development from `New` or `Clarifying` unless the requester explicitly instructs you to do so.

Do not commit, push, merge, rebase, force push, tag, release, or deploy without explicit approval from the project owner or authorized reviewer.
